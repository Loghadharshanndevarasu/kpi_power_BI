# KPI Power BI Dashboard

A Power BI dashboard project focused on KPI-oriented data visualization and business reporting.

## What it demonstrates

- KPI dashboard design
- Business reporting and visualization
- Power BI report development
- Turning structured data into management-facing insights

## Files

The repository contains Power BI report files:

- `FDIC.pbix`
- `KPI_power_BI_dashboard.pbix`

## Project perspective

This project is particularly relevant to Business Analyst roles because the focus is on presenting business information through KPIs and dashboards rather than only on software development.
